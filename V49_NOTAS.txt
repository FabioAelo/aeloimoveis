AELO IMÓVEIS — V49 TEMPORADA

Primeira etapa do módulo de aluguel por temporada.

1. Execute temporada_v49.sql no SQL Editor do Supabase antes de cadastrar temporada.
2. Publique os arquivos deste ZIP no GitHub Pages.
3. No painel administrativo, escolha “🌴 Aluguel por temporada”.
4. Informe diária, fim de semana, alta temporada, limpeza, mínimo de noites, hóspedes e horários.
5. O catálogo ganha a categoria “🌴 Temporada”.
6. O Assistente AELO ganha um fluxo específico para temporada, usando somente imóveis reais publicados.

A V49 não cria reserva/pagamento online e não declara disponibilidade por data. Isso fica para a próxima etapa, com calendário de disponibilidade.


V49.2 — MANUTENÇÃO

V49.3 — BUSCA DE TEMPORADA
1. O botão “Encontrar hospedagem” agora abre uma busca de temporada real dentro da página.
2. A busca usa imóveis reais publicados do catálogo AELO.
3. Filtros: região/bairro, check-in, check-out, hóspedes, tipo de imóvel e diária máxima.
4. A diária utiliza nightly_price quando preenchido, com fallback para price.
5. Datas são usadas para qualificação da busca; a versão ainda não declara disponibilidade automática por data.
6. Resultados permitem abrir a ficha completa do imóvel.
7. Quando não há resultado, há encaminhamento para a AELO via WhatsApp.
8. Mantidas RLS, Data API e demais tabelas sem alterações.
