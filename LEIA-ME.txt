AELO IMÓVEIS — V8 / BANCO DE DADOS

O site agora pode buscar imóveis do Supabase. Sem configuração, ele continua exibindo os imóveis demonstrativos.

1) Crie um projeto no Supabase.
2) No SQL Editor, cole e execute database.sql.
3) Em Authentication > Users, crie o usuário administrador com e-mail e senha.
4) Abra Project Settings > API e copie a Project URL e a chave anon/publishable.
5) Edite supabase-config.js:
   url: "https://SEU-PROJETO.supabase.co"
   anonKey: "SUA_CHAVE_ANON_OU_PUBLISHABLE"
6) Publique todos os arquivos no mesmo repositório do GitHub Pages.
7) Acesse admin.html, faça login e use “+ Novo imóvel”.

SEGURANÇA
- Nunca use a chave service_role no navegador.
- O banco usa RLS: imóveis são administrados pelo usuário autenticado que os criou.
- O site público só mostra imóveis com is_published = true.

FOTOS
- O painel envia a foto para o Storage do Supabase no bucket property-images.
- O banco grava a URL pública da foto.
